# builder-content-guide 1.0.2

## English

Fixed: Normal WordPress updates are independent of the optional catalog, with bounded downloads and stricter package validation.

Misc: Bundles deckerweb Library 1.3.0 and Updater 2.4.0. Features and minimum requirements remain unchanged. The bundled updater remains active alongside other deckerweb plugins.

## Deutsch

Behoben: Normale WordPress-Updates sind unabhängig vom optionalen Katalog, mit begrenzten Downloads und strengerer Paketprüfung.

Sonstiges: Enthält deckerweb Library 1.3.0 und Updater 2.4.0. Funktionen und Mindestanforderungen bleiben unverändert. Der mitgelieferte Updater bleibt neben anderen deckerweb-Plugins aktiv.
